# Stock Price Predictions
![Graph showing output results](readme_images/output_graph.png)

## Description
This repository contains code and analysis used for a research paper exploring the use of AI&ML approaches to predicting stock prices. The project is not a live trading bot or any sort of financial tool. It aims to showcase the accuracy and feasibility of AI&ML approaches from a simulation.

## Contents
- `comparison/` – Graphs and CSV files used to communicate results in the research paper  
- `data_collection/` – Code files used to make API calls and fetch all the data used for the project  
- `eda/` – Exploratory Data Analysis graphs used to introduce the dataset in the research paper  
- `modeling/` – Code files used to define the neural network and save appropriate results  
- `sim_dump_3000/` – Example file containing outputs from the simulation run with $3000 invested in the early 2022 stock market  
- `trading/` – Code files used to define logic for simulated trading and portfolio inventorying  
- `trade_script_simulated` – Main code file used to simulate the neural network over the early 2022 stock market
